怎么装

插件是纯资源包，不含任何代码，装错了也不会弄坏启动器。

方式一 · 启动器内一键安装（开发中）

启动器「插件」页里的市场入口正在做，当前 v1.9.4 还没有 —— 做好之前请用下面的方式二。 这一栏写在这里是为了让你知道进度，不是为了让你去点一个不存在的按钮。

方式二 · 手动导入（现在就能用）

  1. 下载插件包。点卡片上的「下载」—— 它走 gh-proxy.com 国内镜像。 旁边的「GitHub 直链」是同一个文件（可自行核对 sha256），能连上 GitHub 时用它更快。
  2. 不要解压。启动器要的就是这个 zip 本身。
  3. 打开启动器 → 进入控键布局管理 → 点「导入」→ 在文件选择器里选刚下载的 zip。
  4. 导入完成后，在布局列表里选中它即可生效。界面排版类插件需要退出主页再进一次。
关于安全：这些插件包里只有 JSON 文本和图片。生成脚本会拒绝任何 .dex / .jar / .so 文件， 所以不存在「插件里藏代码」的可能。每个包的 sha256 都在目录里公开，可自行核对。
为什么默认给镜像：github.com 在中国大陆是时通时断的 （实测同一分钟内可通、也可连续 20 秒连不上）。gh-proxy.com 只是把同一条 GitHub 直链转发一遍，下到的字节完全一样 —— 本页所有插件的下载链接都已按 sha256 逐个核对过。
